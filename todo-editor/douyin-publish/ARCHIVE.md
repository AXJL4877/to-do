# 成片投放目录

把一整条成片放进这个文件夹，发布台资产库会自动出现（约 3 秒扫一次）。

**目录：** `d:\Desktop\数据系列板报\douyin-publish\archive\inbox`

## 一条成片 = 一个子文件夹

文件夹名建议：`交易日-盘段-板块`，例如 `2026-08-27-noon-gain`。

```
inbox/
  2026-08-27-noon-gain/
    video.mp4          竖屏成片，发抖音才需要（纯图资产可省略）
    cover-3x4.png      竖封面 3:4（默认只出这张；生图自带大标题，禁止后期贴字）
    cover-4x3.png      横封面 4:3（默认不出，仅明确要求时）
    avatar.png         可选；头像等资料图，可单独推到手机相册
    background.png     可选；主页背景等资料图
    other/             其他不固定资产（任意图/短视频文件名）
    meta.json          标题 / 简介 / 标签
```

扫描认视频、封面、`avatar`、`background`，以及 `other/`（和夹内非约定文件名的散图）。**无视频也可以进资产库**；发布台「发送资产」会把现有图片推到手机相册（不要求 video.mp4）。「发布」选片流程仍需要视频。

## 封面风格

- **默认只出竖封面 `cover-3x4`**；不要默认再出 `cover-4x3`。
- **大标题由生图模型画进画面**：prompt 里写出可读大标题；缩略图也要能读清。
- **禁止后期贴字**：不要 Pillow / ffmpeg / 模板叠加文字；不要先出无字底再编码打标题。
- **风格按每条成片**：跟该片主视觉/板书/榜单 UI 一致，在同一套生图风格里画标题。
- 封面上的大标题与 `meta.json` 的 `title` 同义或同句。

## meta.json

```json
{
  "title": "今日盘中涨幅 TOP50",
  "caption": "今日盘中涨幅TOP50来了。领涨花溪科技+30%。公开行情整理，仅供参考，不构成投资建议。",
  "tags": ["A股", "涨停", "财经速报", "盘中速报"],
  "board": "gain",
  "trade_date": "2026-08-27",
  "session": "noon"
}
```

`session`：`noon` 午盘/盘中，`close` 收盘。`board`：`gain` `drop` `industry` `concept` `stock` 等。

没有 `meta.json` 时，资产库用文件夹名当标题。有视频或任意图片就会出现；都没有的文件夹不显示。inbox 根目录直接丢文件 **不会**出现。

成片台点「本条成片」也会按这套结构写入同一目录。别的 agent 入口：仓库根 `AGENTS.md`。
