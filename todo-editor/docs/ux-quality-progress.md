# 商业化交互与性能改进记录

更新：2026-10-03。完整目标仍在进行，不能以本轮回归通过代替整软件验收。

## 本轮实现

- 口播设置和逻辑线使用可编辑字段；确认时保留编辑值及素材引用。
- 失败重试、生成结果过期检查、退出/清空/切换工程时的阶段请求取消。
- 候选完整正文、打磨修改前后对照、允许拒绝全部打磨建议。
- 打磨在原段落中应用，保留版本；拒绝位置不明确或锁定段落的修改。
- 问答区可拖动和键盘调整高度；固定底部操作，内容单独滚动。
- 修复 CreativeProgress 外层/内层主题类名冲突造成固定高度裁切，状态说明换行。
- AI 应用内浮窗可缩放，移动/窗口改变后保持在视口内。
- 发布台“文案+封面并行”各自完成立即展示，单项失败保留另一项成功结果。

## 验证入口

- `npm run build`
- `node scripts/test-script-workbench.mjs`：真实 Electron DOM，16 项回归；1280×800、900×650、640×560 确认按钮边界检查，截图写入 `native/test-output/script-workbench/`。
- `node scripts/test-independent-tasks.mjs`：快任务立即完成、慢任务继续、部分失败不丢成功结果。
- `scripts/script-stage-selfcheck.mjs` 与 `scripts/script-memo-doc-selfcheck.mjs` 可用 esbuild 内存打包后运行。
- AI 回归使用模拟响应，没有调用付费 AI、没有发布内容。

## 后续必须完成或核实

1. 口播正文与项目/素材/发布元信息分区，手改正文与阶段草稿一致；目前 `buildMemoFromWorkspace` 仍可能用草稿覆盖手工修改，统计也包含元信息。
2. 局部改写请求仍需生命周期隔离及编辑冲突处理；阶段请求隔离已做，但不能据此认定所有 AI 请求都安全。
3. 阶段回退/版本恢复与定稿进入配音、封面、发布的端到端交互；历史节点目前只有动作元数据。
4. 生图任务轮询去重、后台生命周期、任务状态恢复和真实服务失败回归；现有服务本身已支持异步队列，不要再造一套。
5. 发布台切换资产/工程时的旧响应隔离；一键文案+封面+投放仍走另一分支，需要保留部分成功和避免误写资产。
6. 全工作区侧栏/属性/底部面板的缩放限制、长内容和缩放倍率检查。
7. 动效统一并量化性能：减少无效渲染，检查长列表/片段多时表现；不能只凭构建通过声称高性能。
8. 实际运行的整软件视觉验收、性能数据与真实生成流程验证；目前截图仅覆盖口播工作台。
