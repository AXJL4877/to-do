# JIZURA 短句动态花字接入设计

日期：2026-10-02。状态：待用户审阅。

## 目标与范围

用户希望把 JIZURA 的动态文字效果整合到现有花字库，已认可先做短句动态花字的方向。
第一阶段交付流程：选择动态预设 → 输入文字 → 调字体、颜色、字号、运动强度和动画时长 → 播放或拖动预览 → 换一版组合 → 加入时间轴。
入轨后仍是可编辑文字片段，支持修改、复制、撤销、工程保存和重新打开。导出使用与预览相同的绘制实现。
整段歌词自动分句、音频 BPM 分析、逐字配音对齐、跨片段自动转场不在本阶段范围。

## 方案选择

采用“抽取 JIZURA 引擎和选定效果包 + 本地适配器”，在现有花字面板增加动态分类。
嵌入整套网页会带来独立工程和时间轴，不符合直接编辑文字片段的目标；完全重写所有效果成本高，也难以保持原始表现。

## 上游来源与边界

已分析的上游版本文件为 0.10.1，提交为 `fc16bfe43ea4a6c25a21f1caf04d17326de14f00`。
源仓库：https://github.com/852wa/JIZURA 。接入时固定该版本，保存原始 MIT LICENSE、版权声明和本地修改说明。
引入绘制、字体测量、样式、效果注册及必要的规划辅助代码。保留有明确用途的源文件边界。
排除上游编辑器 UI、音频存储、WebCodecs 导出、MP4 muxer 和 AE/CEP 接口。
上游全局 `window.J` 改为适配器内部引擎实例，不与应用或其他插件共享全局命名空间。
应用使用编译后的本地代码，不运行用户提供的脚本，也不动态下载效果包。

## 首批效果与交互

新增“动态花字”分类，首批六个预设使用已存在的上游布局键：

| 显示名 | 布局键 | 表现 |
| --- | --- | --- |
| 弹入标题 | center | 中心标题配合入场和退场动作 |
| 打字显现 | type | 按时间显现文字 |
| 波浪文字 | wave | 文字位置呈波浪变化 |
| 逐词叠入 | knSlamStack | 词组依次落入并堆叠 |
| 流动归位 | knFlowSnap | 词组流动后排列归位 |
| 十字排版 | tyCross | 文字交叉排列 |

每个预设固定布局，并提供有限的兼容入场、保持、退场和装饰组合。
“换一版”只改变当前文字的种子和允许的组合，保持文字、字体、颜色和时长。
输入上限沿用当前面板的 300 字。多行文本保留换行；上游歌词标记不解释，`/`、`*`、`[]` 等作为普通文字保留。
短句是主要使用场景；超过选定布局的适用字数时，回退到完整显示文字的中心排版，并显示简短提示。
动态模式显示运动强度和动画时长；描边、粉笔手、字内纹理等未接入的调整项不在动态模式显示。
保留字体、字号、文字主色和强调色控制。预览提供播放、暂停、重播、进度拖动以及深色/透明底切换。
预览使用当前工程画幅比例，缩放放入面板，不以旧的 640×200 比例强行压缩构图。

## 文档数据

在 `FancyText` 增加可选的 `dynamic` 配置。旧花字和粉笔配置保持兼容。
配置只保存可序列化数据：`version: 1`、`engine: 'jizura'`、`presetId`、32 位 `seed`、动画时长 `duration`、0～1 的 `motion` 和强调色 `accent`。
正文仍在 `TextStyle.content`，字体、字号和主色仍使用原有字段，避免保存两份不同值。
完整规划和画布只属于运行时缓存，不写入工程。缓存键包含全部有效输入、画幅和引擎版本。
复制片段保持种子；保存重开保持同一组合；用户主动“换一版”才改变种子。
动态预设的普通 `animIn` / `animOut` 设为 `none`，由动态引擎统一管理入场与退场，避免重复叠加。
切换回粉笔或普通花字时清除动态配置；切换到动态预设时清除粉笔配置。
未知配置版本或失效预设使用普通文字回退并在花字面板提示，不使项目打开或导出失败。

## 渲染与时间

增加独立动态花字适配器，由 `drawTextClip` 调用，接收文字样式、工程宽高、片段局部时间和片段时长。
引擎始终在独立透明画布绘制，然后以居中坐标叠加回调用者画布，避免上游 clearRect/setTransform 清除视频或其他图层。
位置、旋转、缩放、透明度、片段效果和转场继续由现有片段合成层管理。
适配器编译单个文字镜头，不使用整段歌词自动规划流程；镜头参数由预设、种子和文字决定。
动态布局按工程画幅生成，以字号相对默认字号的比例整体缩放，保留现有字号关键帧的作用。
播放、跳播和反向拖动都直接按局部时间求帧，不依赖上一帧状态。
`duration` 表示一次完整动画的时长；新建片段默认长度至少覆盖该时长。片段变短会裁掉后续动画，并在面板提示。
片段超过动画时长时保持退出前的可读帧；退场放在片段末尾，避免长片段中途变空白。
镜头进度及入场、保持、退场必须由同一时间映射计算，测试包含长于和短于配置时长的片段。
时间量化策略预览与导出一致，不能因预览开启快速模式而改变布局或运动轨迹。

## 确定性与字体

将引入代码中实际使用的 Math.random 纹理改为由种子决定，或关闭对应纹理；不修改全局 Math.random。
默认禁用整屏背景、HUD、纸张和颗粒背景，只保留透明文字及预设声明的局部装饰。
字体映射到用户选定的本地字体，所有测量和绘制使用同一映射。没有选定字体时沿用应用的中文回退字体。
第一阶段不从 Google Fonts 请求字体。字体准备完成后清空相关测量/规划缓存并重绘。
隐藏导出窗口先加载与预览一致的字体，再开始逐帧渲染。
引擎的语言和字体设置按每次绘制输入设置，保证不同字体、颜色和种子的片段不会相互影响。

## 模块与导出接入

- 上游核心/选定效果包：保存在本地第三方代码目录，附带许可证及来源信息。
- 动态适配器：负责配置验证、单镜头规划、离屏绘制和有界缓存。
- `src/types.ts`：声明可保存的动态配置，不存函数或 DOM 对象。
- `src/lib/fancyText.ts`：增加分类与六个预设。
- `src/components/FancyTextPanel.tsx`：编辑动态参数，预览和入轨仍使用现有面板流程。
- `src/lib/monitorDraw.ts`：在普通文字入退场处理前分派动态绘制。
- `src/chalkRender.ts`：沿用共用 drawTextClip，并补齐动态字体准备。
- `electron/chalkTextExport.cjs`：保持现有透明动画 MOV 导出路径，检查动态片段一定逐帧渲染。

预览及导出共享适配器，动态功能不依赖独立的视频生成服务。缓存设置容量上限，失效规划及时释放，避免每个片段永久占用独立大画布。
引擎导入仅注册效果，不在普通项目启动时生成颗粒或建立多个全尺寸缓冲区；首次使用动态花字时初始化渲染资源。

## 验证与验收

1. 浏览器测试：六个效果在中文、英文、混合文本以及横竖画幅下出可见文字；超长文本回退后完整保留正文。
2. 确定性测试：相同配置、种子和时间在独立实例中像素一致；跳播前后同一时间像素一致。
3. 合成测试：透明空白区域保持 alpha=0；绘制前后的其他图层像素不被清除；多片段字体和配色不串扰。
4. 交互测试：切预设、改字、改色、换种子、入轨、选中后修改、撤销、重做和复制均保留正确数据。
5. 工程测试：保存重开保留文字和组合；旧工程不含 dynamic 字段仍正常；未知版本按普通文字回退。
6. 时间测试：连续播放、拖动、裁短及加长片段的入退场与提示一致；字号关键帧生效。
7. 导出测试：调用隐藏渲染窗口与正常预览比较同一配置、尺寸、时间的像素，并验证透明动画素材可合成。
8. 回归检查：现有花字、粉笔字及相关导出测试；运行 TypeScript 检查和生产构建。

已知基线：上一轮完整构建有 AiPanel/SkillsPanel 的 skill 可空类型错误；时间轴浏览器测试存在 Alt 滚轮缩放失败及一次文字像素失败。实施前重新检查基线，遇到阻碍动态接入验证的错误再定位，不能把已有错误计为新功能通过。
