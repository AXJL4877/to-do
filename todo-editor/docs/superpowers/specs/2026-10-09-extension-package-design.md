# TODO 扩展包安装设计

用户要求：分析黑板手绘与动态文字的现有接入结构，形成后续作者可复用的准则、格式和示例，并实现拖入扩展包自动识别安装。保持现有黑白灰剪纸界面。

现有 skill.json、style.json、anim.json 继续作为能力描述；新增 todo-extension-pack/1 分发容器。文件扩展名为 .todoext，内容为 ZIP，根目录 extension.json 声明 kind、manifest 和所有文件的大小及 SHA-256。沿用既有校验器和用户目录扫描，不创建第二套任务系统。

导入流程：窗口捕获文件拖入 → 区分扩展与媒体 → 二进制上传 → 检查包结构、资源限制、文件校验和现有 manifest → 临时目录验证 → 原子安装/升级 → 触发列表刷新 → 显示结果。安装本身不运行脚本、不开生成任务。已有媒体拖入仍走原来的导入流程。

同 id 同内容重复导入不改动；同 id 新版本替换用户包，失败恢复原包；拒绝旧版本、同版本不同内容、覆盖 builtin 命名空间及路径越界。原生渲染引擎仍由宿主提供，包不能新增任意浏览器 JavaScript 引擎；Python 包依赖既有渲染协议和运行环境。

验收：打包、安装、升级、重复导入、损坏/非法路径拒绝，HTTP 上传与 Origin 限制，浏览器拖入拦截和普通媒体分流，现有扩展目录刷新，生产链路与构建回归。
