# 黑板渲染性能实施计划

**Goal:** 在保持独立透明元素、笔画顺序、笔尖轨迹和宿主编辑能力的条件下降低黑板渲染成本。

**Architecture:** 优先缩小手绘工作区域，保留原全画幅参考路径与固定样例对比；手图等只读资源在进程内复用。独立镜头采用隔离 Python 进程并发，按内存/CPU限额控制并发与内部线程。测量后决定是否需要 GPU；不把硬件编码当成绘制加速。

**Tech Stack:** Python/OpenCV/NumPy、Node 调度、FFmpeg 透明 VP9。

**Spec:** 用户认可的顺序：局部画布 → 预计算与缓存 → 镜头并行 → 根据实测评估 GPU 绘制。

## 约束

- 不改用户工程，不调用付费 TTS/生图；合成固定图像作为基准。
- 笔尖仍以原画幅坐标返回，元素视频 crop/尺寸/时长不变。
- 不无限并发，不并发修改同一 Python 渲染器；不丢失透明/声音/独立元素。
