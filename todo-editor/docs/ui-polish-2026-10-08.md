# 工作区 UI 与交互优化

日期：2026-10-08

## 改动

- 按用户提供的参考图采用暖白纸面、细描边、灰蓝选中状态和少量偏移阴影，统一字体回退、文字对比度和控件间距。
- 媒体导航采用纯图标布局，悬停显示名称；当前分类和“更多”展开状态可被辅助技术识别。
- 恢复细滚动条与键盘焦点；短窗口中的背景设置和媒体列表可以滚动访问。
- 900px 以下窗口按需展开属性栏，预览区域优先；预览优先模式可继续隐藏侧栏。
- 面板分隔条支持方向键调整，Shift 加速；全局剪辑快捷键不会截获这些方向键。
- 面板拖动按动画帧合并位移；处理取消、失焦、释放及其他指针干扰。从实际显示宽度开始计算，避免窄窗口出现拖动无反馈。

## 验证

- `npm run build`：TypeScript 与生产构建通过。仍存在已有的大文件分块警告，本轮未改动预览引擎和资源分块策略。
- `npm run ui:test`：真实 Electron DOM 检查，15 项；1440×900、1024×768、800×650、640×560 布局与截图。
- `npm run timeline:test`：时间轴算法与 16 项浏览器回归。
- `node scripts/test-script-workbench.mjs`：19 项口播工作台回归通过；使用模拟响应。
- 独立代码审查发现并修复了分隔条与全局方向键的冲突，以及保存宽度超过显示宽度时的缩放死区。

定量结果仅针对缩放事件合并：同一动画帧内 120 次模拟移动从 120 次布局回调降为 1 次，完整保留 120px 位移。这不等同于整软件帧率提升。

时间轴测试修正了两个前提：片段位置与宽度按整数像素边缘比较；文字采样区域必须在画布可视范围内，并在测试结束时恢复布局。未放宽文字不被拉伸的断言。

截图与结构化结果位于 `native/test-output/workspace-ui/`。本轮更新源码和前端构建，未重新生成安装包。

## 播放头拖动跟进

用户反馈鼠标拖动播放头不够顺滑。真实指针回归复现了开启吸附、时间轴放大到 600px/秒、30fps 时，1px 移动被帧取整吞掉的情况。现在拖动中的 live 播放头连续跟随指针，松手按吸附设置落帧；Shift 仍吸附切口。拖动期间不逐事件写入工程状态。

## 参考图风格跟进

静态参考图提供了视觉语言，无法确认原图的实际动画。实现采用 120–160ms 的悬停反馈、弹层短距离淡入与属性区展开反馈，取消弹层放大弹跳；属性折叠箭头连续旋转。系统减少动态效果设置仍生效。媒体分类继续仅显示图标，名称由悬停提示提供。视频内容本身不因主题改变而重新着色。
