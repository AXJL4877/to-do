## 手动安装

需要包含 **corner-chain 文字适配** 的 TO DO（2026-10-09 本次源码更新或后续兼容构建）。旧版 TO DO 仅安装包不会自动获得新渲染器，可能退化为普通文字编排；请先更新宿主。本包不携带可热加载的浏览器 JS，也不会自动修改宿主。

把 deliverables/corner-chain.todoext 拖入更新后的 TO DO，进入「拓展 → 转角推进」，输入口播文案生成。安装不会自动开始生成，也不会修改你的工程；本次开发只在隔离测试目录安装验证。

使用已有 TTS 配置，可选择咪仔或克隆音；实际生成需要已有配音服务凭据。分段默认按段落；每个配音段重新开启转角链，空行/--- 表示重新开段。字幕默认关闭，因为主画面已经显示完整口播原文。

字体选择微软雅黑、黑体、得意黑、楷体、宋体、Arial 或本机自定义名称。所选字体必须存在；缺字或未安装时浏览器使用微软雅黑等后备字体。包不分发第三方字体。预览和导出需使用同一字体环境。

## 编辑与边界

成片在时间轴中保留原生文字，与 TTS 音频相连，可改字、字体、大小、变换与关键帧。工作台改字后重生成会重算邻句的接点；单片段内改字只覆盖当前文字场景，跨片段同步编辑应通过工作台。

旧句会随镜头退出画面；最多保留四个历史对象，长文使用当前句坐标重建，避免无限缩放数值失真。短句的转角时长自动压缩，不会拖慢 TTS。具体内部字体样式没有真实粗体的字体会使用浏览器合成粗体。
